# Installing 
- Put both **aCalc.c** and **install-aCalc.sh** inside the *~*.
- Then run `bash install-aCalc.sh`.
- Wait until script ends.
- Test the calculator by typing something like `acalc add 10 5` in the terminal.
- It will print the answer.
- The Calculator save every output in a file.
- You can read it using `cat ~/calc_history.txt`.
